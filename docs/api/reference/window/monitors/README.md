# Monitors

| Item | Role |
|---|---|
| [`Monitors`](monitors.md) | Connected-monitor snapshot collection |
| [`MonitorInfo`](monitor_info.md) | One monitor's metadata |
| [`VideoMode`](video_mode.md) | Resolution, channel depth, refresh rate |

Monitor position, physical size, work area, content scale, and mode data are backend snapshots and
may use GLFW sentinel values when unavailable. See the generated
[platform compatibility matrix](../platform_compatibility.md) and exhaustive
[GLFW inventory](../../../maintenance/glfw_platform_inventory.md).
